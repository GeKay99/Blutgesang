        GitHub-Verbindung und Sicherheit konfigurieren

        GitHub Repository

        Erstelle ein Personal Access Token unter GitHub → Settings → Developer settings → Personal access tokens. Der Token benötigt den Scope repo (oder contents: write für Fine-grained tokens).

        Passwort ändern

        Standard-Passwort: BlutgesangAdmin – bitte nach dem ersten Login ändern. Das Passwort wird als SHA-256-Hash im LocalStorage des Browsers gespeichert.
